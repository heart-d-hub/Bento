# คู่มือเข้าใช้งาน Bento (แยกบทบาท)

คู่มือนี้แบ่งวิธีเข้าใช้งานเป็น 2 กลุ่ม:
- ลูกน้อง/ผู้คีย์ข้อมูล (ใช้งานระบบ)
- ผู้พัฒนา/ผู้ดูแลระบบ (แก้ไขระบบ/ตรวจฐานข้อมูล)

---

## 1) สำหรับลูกน้อง (ใช้งานประจำวัน)

### วิธีเข้าโปรแกรม
1. เปิดคอม
2. ดับเบิลคลิก `start-bento.bat` (หรือชอร์ตคัตที่ชี้มาที่ไฟล์นี้)
3. รอโปรแกรม `Bento` เปิด
4. ล็อกอินด้วยบัญชีพนักงาน

### ข้อสำคัญ
- ไม่ต้องเปิด Cursor
- ไม่ต้องเปิด Prisma Studio
- ไม่ต้องเปิด pgAdmin4
- ใช้เฉพาะเมนูที่ได้รับสิทธิ์

---

## 2) สำหรับผู้พัฒนา/ผู้ดูแลระบบ

### วิธีเข้าแบบแอดมิน
1. เปิดคอม
2. ดับเบิลคลิก `start-bento-admin.bat`
3. ระบบจะเปิด:
   - Bento app
   - pgAdmin4
   - Prisma Studio

### ใช้เมื่อไหร่
- ต้องตรวจ/แก้ข้อมูลฐานข้อมูล
- ต้องทดสอบฟีเจอร์
- ต้องดูโครงสร้างข้อมูลหรือดีบัก

---

## 3) กรณี `app.exe` ไม่อยู่ path มาตรฐาน

รันผ่าน PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File ".\scripts\start-bento.ps1" -AppPath "D:\path\to\app.exe"
```

---

## 4) คำแนะนำการตั้งสิทธิ์

- บัญชีลูกน้อง: ให้เข้าเฉพาะงานที่ต้องทำ (เช่น แฟ้มข้อมูลสินค้า)
- บัญชีแอดมิน: จำกัดเฉพาะเจ้าของ/หัวหน้าที่รับผิดชอบ
- ห้ามใช้บัญชีร่วมกัน
- ให้ logout ทุกครั้งเมื่อเลิกงาน
